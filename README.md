# 🏨 AI Travel & Hotel Booking Agent

## 📌 1. About the Project

This project is an **AI-based Travel & Hotel Booking Agent** developed as part of **SLE-1 for Introduction to Artificial Intelligence (02AML204)**.

The agent helps users find a suitable hotel based on their travel requirements such as:

- 📍 Destination
- 💰 Maximum budget per night
- ⭐ Minimum hotel rating
- 👥 Number of travelers

The system processes the user's requirements, searches the available hotel data, filters unsuitable hotels, compares the available options, and recommends the most suitable hotel.

---

## 🎯 2. Objective

The main objectives of this project are:

- To develop a simple AI-based hotel recommendation system.
- To understand how an AI agent processes user requirements.
- To filter hotels according to user preferences.
- To compare suitable hotels using different factors.
- To recommend the best available hotel.
- To demonstrate basic AI decision-making using Python.
